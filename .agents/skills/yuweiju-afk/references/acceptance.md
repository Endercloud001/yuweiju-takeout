# 人工验收准备与反馈

入口：独立验证已通过，候选和启动前授权已明确。根据当前业务验收项生成一页交接，不复制 issue 专用旧脚本；复用现有 environment 和启动/停止入口。

1. 核对候选提交/产物、隔离与真实验收区别、服务授权和副作用。真实验收涉及登录创建用户、员工写入、缓存或外部调用时列明实际影响与现有授权；原账号由本人输入，不重置原账号制造成功。缺少真实配置仅报告入口和准备方式。
2. 已授权时自动启动本票前端、后端及必要隔离依赖。检查端口，选择可用端口，绑定127.0.0.1；保留其他任务服务。使用精确候选产物，不把旧服务当成新候选。保存本票容器名/PID及所有权、启动日志、候选、URL和停止入口。停止脚本只操作记录的具名资源，保留卷；PID 启停前核对进程/启动时间防止误杀复用 PID。Windows 后台启动用隐藏窗口。
3. 用户交接前检查前端资源、代理请求、后端健康和未登录受保护请求。静态服务必须正确处理 URL 编码的中文资产及 MIME；可复用 [环境静态服务](../../../../.sandcastle/environment/README.md#管理端静态验收服务)。真实登录后打开本票完整路由，确认资源加载、图片解码及页面错误，保留首次失败截图。健康HTTP200不能代替权限断言；页面删除按当前 handler/失败协议验收。验证失败先修正已授权技术问题，不将未就绪服务交给用户。
4. 一页说明列：URL、候选提交、隔离/真实环境、步骤、预期、反馈、日志关联时间、停机方式与约定保留期限。所有必需验收一起说明。合成账号仅用于隔离；真实微信至少确认同账号身份稳定、不同账号数据/访问隔离，具体项由 issue 决定。
5. 保存用户反馈，仅追问缺项。全部必需项通过后按已有交付授权进入 yuweiju-deliver，并按约定停服务；缺少交付权限只补权限。人工等待不计模型编码时间。到期按事先约定停止并给恢复入口；没有到期约定则先收集，不能静默清卷。

完成条件：服务探针和日志就绪；反馈与准确候选对应；所有必需验收分别有“通过/失败/未执行”，隔离通过不能代替真实通过；issue关闭取决于全部必需验收与关闭授权。

官方小程序验收优先复用已受信任的项目，保留维护者 project/private 配置；源码更新后明确提醒点击“编译”，收到重编译确认再运行依赖新产物的驱动。截图调用设置有限超时（例如30秒，由所用 SDK 支持的参数或进程 timeout 实现），记录超时并保留其他检查，不让截图无限阻塞。记录自动业务检查、官方 SDK 和人工反馈各自的版本与结果；截图失败不能推定业务失败或人工通过。信任或安全设置由维护者处理，服务及合成数据按已有保留/停止约定处理。

启动前能力检查为本票选择独立且可用的自动化端口，记录端口、项目路径与实际页面身份；保留其他任务端口。通用游客夹具或旧任务截图成功只证明旧项目能力：在本票实际项目取得一张可查看截图才证明本票截图能力就绪。遇到 saveFile 限额或截图超时，保存错误与未执行项，核对本票端口/项目后仅修正本票准备，不清理他票存储。必要截图无法取得时，按启动 handoff 明确受阻或已授权的仅候选交付。

页面驱动先核对当前 swiper pane，详情按实际展开状态选择行；需要完整明细时触发真实“展开更多”事件再断言。图片加载失败等待本行具体兜底状态，设置有限总超时并记录最后状态，不能以固定短延时或所有 pane 的元素总数判断失败。事件绑定和源切换问题仍由普通渲染/事件测试检查；这些指引不增加截图门槛。

官方 SDK 驱动按实际 WXML 注册事件触发点击、滚动等交互；Vue 实例方法不一定是原生 Page 方法，先检查事件注册再选择驱动方式。例如分页触发 scroll-view 的 scrolltolower，核对请求页码与新增条目，不能用失败的 Page.callMethod('lower') 代替用户滚动。导航检查读取实际当前路由、订单 ID 及共享 store 的金额交接。旧页面 data 读取超时时，保留调用/超时记录；若这些替代证据覆盖该项“导航与交接”要求，可记录该项通过及 data 未读取的限制，不能宣称支付处理或目标页渲染通过。缺少等价证据的业务项仍为未执行/受阻，不能因 SDK 限制跳过。

tap 后旧连接的 data 超时，先保存失败调用、时间和最后路由；在已核实的同项目/同自动化端口，有限超时内断开旧连接并建立新连接，重新取 currentPage 和页面对象，再读实际目标路由、订单 ID 与页面字段。导航可能已经完成，重新连接不应重发支付/取消等写交互；先用真实受保护 API，必要时用已授权的隔离库只读查询核对持久状态，再判断是否仍需执行下一步。新连接继续超时则记录该读取未执行及可取得的等价证据；驱动 exit0、tap 返回或成功页路由单独不能证明支付与履约完成。本指引不代表已经实现通用 SDK 重连工具。

逐场景记录版本、事件、预期、实际结果和证据路径，分清 API 替身、真实隔离后端及真实微信结果；归属/匿名拒绝由真实认证后端核对，合成替身只证明页面联动。已成功取得的同一候选截图在源码未变且来源明确时复用，避免重复截图超时；保留首次失败，不把替代检查写成原调用成功。

用户可用一条回复：

```text
候选版本：…；隔离验收：1通过/2通过；真实验收：通过或未执行；异常：无或步骤、页面提示和操作时间；服务：停止或保留至…
```

本参考描述任务相关服务编排；本次维护不会启动某业务票的人工验收服务，也不声称已有通用服务启动器。
