### 16. user_behavior_feature_snapshot

user_behavior_feature_snapshot 表用于保存用户行为特征快照，按天固化训练与推理所需的用户特征，避免训练时出现“数据穿越”
| 字段              | 数据类型       | 说明                     | 备注 |
| -------------------- | -------------- | ------------------------ | ---- |
| id                   | bigint         | 主键                     | 自增 |
| snapshot_date        | date           | 快照日期                 | user_id、feature_version 组成唯一|
| user_id              | bigint         | 用户id                   | 关联 user.id（本项目默认不加外键约束|
| rfm_recency_days     | int            | 最近一次下单距今天    | RFM 特征 |
| rfm_frequency_30d    | int            | 0天下单次          | RFM 特征 |
| rfm_monetary_30d     | decimal(10,2)  | 0天消费金          | RFM 特征 |
| order_lunch_ratio    | decimal(6,4)   | 午餐时段下单占比         | 默认 0，范[0,1] |
| order_dinner_ratio   | decimal(6,4)   | 晚餐时段下单占比         | 默认 0，范[0,1] |
| order_night_ratio    | decimal(6,4)   | 夜宵时段下单占比         | 默认 0，范[0,1] |
| price_low_ratio      | decimal(6,4)   | 低价带偏好占          | 默认 0，范[0,1] |
| price_mid_ratio      | decimal(6,4)   | 中价带偏好占          | 默认 0，范[0,1] |
| price_high_ratio     | decimal(6,4)   | 高价带偏好占          | 默认 0，范[0,1] |
| category_pref_top1   | bigint         | 偏好Top1品类ID           | 可为|
| category_pref_top2   | bigint         | 偏好Top2品类ID           | 可为|
| flavor_vector_json   | json           | 口味向量                 | 可为空，Multi-Hot TF-IDF 结果 |
| feature_version      | varchar(32)    | 特征版本              | 默认 v1 |
| create_time          | datetime       | 创建时间                 | 默认 current_timestamp |
| update_time          | datetime       | 更新时间                 | 默认 current_timestamp，更新时自动刷新 |

索引说明
- 唯一索引 `uk_user_snapshot(snapshot_date, user_id, feature_version)`：防止同一天重复快照- 普通索`idx_user_snapshot_user_date(user_id, snapshot_date)`：支持按用户回放行为特征

| category_id          | bigint         | 鍝佺被id                   | 閫昏緫澶栭敭 |
| sales_qty_1d         | int            | 1日销                 | 默认 0 |

| weather_code         | varchar(32)    | 天气分类编码             | 天气接口失败时降级为 CLEAR |

### 18. dish_heat_prediction_result

dish_heat_prediction_result 表用于保存热度预测结果，是管理端“热度洞察卡片”和 AI 助手热门推荐的事实来源
| 字段              | 数据类型       | 说明                     | 备注 |
| -------------------- | -------------- | ------------------------ | ---- |
| id                   | bigint         | 主键                     | 自增 |
| window_start         | date           | 预测窗口开始日        | window_end、dish_id、model_version 组成唯一|
| window_end           | date           | 预测窗口结束日期         |      |
| dish_id              | bigint         | 菜品id                   | 关联 dish.id（本项目默认不加外键约束|
| predicted_sales_qty  | decimal(12,4)  | 预测销量                | 默认 0 |
| heat_score           | decimal(12,6)  | 热度得分                 | 默认 0，排序字段|
| model_version        | varchar(64)    | 模型版本              | 例如 analysis-heat-xgb-2026-04-19-xxxx |
| feature_version      | varchar(32)    | 特征版本              | 与快照特征一|
| explain_json         | json           | 解释信息                 | 可为空，包含日销量、近30日销量、衰减热度等 |
| status               | tinyint        | 结果状                | 1有效 0无效 |
| create_time          | datetime       | 创建时间                 | 默认 current_timestamp |

索引说明

### 20. order_risk_feature_snapshot

order_risk_feature_snapshot 表用于存储订单风控识别流程中的特征快照。该表保存的是 **原始（未标准化）** 特征向量，便于后续按不同标准化参数重算。

### 22. order_risk_result

order_risk_result 表为订单风险评分结果表，用于存储模型（或降级规则）给出的最终风险分、风险等级和解释信息（reason_json）。

| 字段名 | 数据类型 | 说明 | 备注 |
| ---- | ---- | ---- | ---- |
| order_id | bigint | 订单id | 与模型版本组成复合主键 |
| model_version | varchar(64) | 模型版本 | 与订单id组成复合主键 |
| feature_version | varchar(32) | 特征版本 | 需与快照/标准化参数对齐 |
| risk_score | int | 风险分(0-100) | |
| risk_level | varchar(10) | 风险等级 | LOW/MEDIUM/HIGH |
| p_lr | decimal(8,6) | LR概率 | 规则降级可为空 |
| p_rf | decimal(8,6) | RF概率 | 规则降级可为空 |
| reason_json | json | 风险解释JSON | 固定 schema（mode/topFeatures/ruleHits/...） |
| evaluated_at | datetime | 评分时间 | 默认 current_timestamp |
| decision_status | varchar(16) | 复核状态 | 默认 PENDING |

索引说明：
- 主键：PRIMARY KEY(order_id, model_version)，支持同订单多模型版本结果共存。
- 普通索引：idx_orr_level_time(risk_level, evaluated_at)，支持管理端风险等级列表与时间范围查询。
- 普通索引：idx_orr_feature_version(feature_version)，支持按特征版本追踪。

#### 订单风险模块数据依赖关系

- 训练输入：order_risk_feature_snapshot + order_risk_standardizer_meta + order_risk_feedback（标签可与业务状态联合生成）
