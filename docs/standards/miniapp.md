# 小程序技术规范

当前小程序包含 uni-app 编译产物与手写页面，尚无完整可重建的 .vue 源工程。修改前辨认可编辑来源；结算/历史页最小编译链由 issue #5/#6 推进，不假定 npm build 可用。

页面注册查 app.json，页面配套 js/json/wxml/wxss；请求分布在 common 和页面，先定位调用点。保留 `authentication` 请求头、正常登录、用户归属、模拟支付及外观；模拟支付不证明真实收付款。

保留公开路径/字段/code、缓存语义；费用展示与服务端可信收费按当前 issue 协调。历史图片保留原明细、缺失兜底；模型坏输出与失败如实提示，不以候选冒充成功。客服保持会话归属、双向消息和连接清理，敏感内容不写日志。

复用 components/static 与 app.wxss，编译产物不批量格式化，不以生成文件手工修改代替可重建来源。局部调整记录后端/管理端调用点与影响。

配置完整性和 Node 语法检查之后仍需开发者工具编译及实际交互验证受影响登录、金额、图片、客服、失败状态。Node --check 不证明官方编译。SDK 使用前查配置及副作用，不代答安全设置。失败/边界测试隔离原库与外部依赖，正常演示按授权记录写入。
