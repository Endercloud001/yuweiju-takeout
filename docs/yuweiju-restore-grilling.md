### 职责验收（Q7 已确认）

- Controller 处理路由、身份上下文、入口参数校验和响应，不承担多步业务事务、状态切换或 SQL 拼接。
- Service 承载业务规则、用例编排和事务。大服务按实际变化职责整理；不追求所有 Service 变薄，不机械统一第四层，也不把算法塞给 Mapper。
- Mapper 承载全部具名业务筛选和统计，Service 不再构造这些数据库条件；简单查询可在 Mapper 内复用 Wrapper，复杂 SQL 按项目规则放 XML。标准主键 CRUD 可继续复用 BaseMapper，不逐条重写框架已提供的功能。业务性的条件更新也在 Mapper 封装，状态判断及是否允许更新由 Service 决定。
- 对整理的用例能从接口找到规则、查询、事务及失败路径；用普通行为测试和受影响三端回归证明兼容，维护者完成讲解与一次小修改，不以文件数/行数验收。
